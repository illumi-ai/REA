## [6.8.0](https://github.com/illumi-ai/REA/compare/rea-agents-6.7.0...rea-agents-6.8.0) (2026-10-21)


###   BREAKING CHANGES

* **mcp:** MCP input advertisements default to compact. Set REA_MCP_INPUT_SCHEMA_PROFILE=full for complete advertised guidance and nested constraints.
* **browser:** console event argument_types may now be null, and console text_capture.status may now be "unavailable", when the CDP producer omits or malforms the argument inventory.
* **reconstruction:** summary.by_evidence_authority keys are now Evidence authorities (shipped-artifact, controlled-replay, historical-reference, external-service, analyst-inference) instead of source states. The previous state counts move to the new required summary.by_source_state. Ledger closure digests change accordingly.
* **native:** Swift conformance type_name and protocol_name can be null when names cannot be resolved; consumers must use typed type_binding and protocol_binding evidence. MachoImportBinding replaces the former Objective-C-specific binding type and schema.
* **browser:** WebSocket event opcode is nullable and numeric values are restricted to the four-bit protocol range.
* **resources:** resource-only observations may have a null Evidence subject and null executable target digests. Clients must use resource_root and reported per-resource provenance instead.
* **browser:** console event timestamps may now be null when the protocol does not provide a finite number.
* **browser:** observe_web_session timeline timestamps can be null when the producer supplies no comparable timestamp. Consumers must handle unknown time explicitly.
* **reference:** Partial reference-source reader results report failed root enumeration in rootFailure instead of a failed directory child at path ".". Historical source graphs preserve the root failure as a top-level limitation.
* **process:** Filesystem enumeration omission reasons now also include entry_unavailable and identity_changed. Clients validating the old literal reason must accept the expanded capture schema.
* **apktool:** Numeric legacy locale selectors such as es-r419 are rejected. Use es-419 or b+es+419. Two-letter region selectors remain supported.
* **plist:** Unresolved XML scalar values now use $plist_type unknown wrappers with element, literal and reason. This replaces the former real/null unknown marker and malformed scalar prefix fallback. Supported extended UTC years now preserve their timestamp.
* **native:** failed or cancelled native UI scenarios now return typed errors with the collected report in partial_observation instead of successful reports containing failed or cancelled steps.
